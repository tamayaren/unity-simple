Matrix4x4

Use one value to describe where a shape goes, which way it turns, and how big it is.

A matrix is like a set of moving instructions for a toy house: make it twice as big, turn it to face right, then place it on a shelf. Apply the same instructions to every corner and the whole house moves together.

A few words first

A matrix is a grid of numbers. Matrix4x4 has four rows and four columns. Unity can fill it for you from a position, rotation and scale. TRS stands for translation (moving), rotation (turning) and scale (resizing).

Local space and world space

Local space means “measured from this object.” World space means “measured from the scene’s origin.” Imagine a cup on a table: its local position says where it is on the table; its world position says where it is in the room.

A matrix can convert between those two descriptions. Start with Matrix4x4.TRS(position, rotation, scale). Unity builds the numbers for you. Use MultiplyPoint3x4 to apply those instructions to a position.

The methods you actually need

MemberUse
Matrix4x4.identityA transform that changes nothing. A default/new matrix contains zeros, not identity.
Matrix4x4.TRS(position, rotation, scale)Build a local-to-world transform. Applies scale, then rotation, then translation.
MultiplyPoint3x4(point)Apply ordinary move, turn and resize instructions to a position.
MultiplyPoint(point)Also supports camera perspective calculations; see the later section.
MultiplyVector(vector)Apply rotation and scale, without translation. Length can change.
inverseReverse an invertible transform. Zero scale makes a transform singular.
transposeSwap rows and columns; useful with inverse for transforming normals.
transform.localToWorldMatrixIncludes the entire parent hierarchy, unlike TRS of local values alone.

Try a point and a direction

Attach this script to an empty object and read the Console. Both results are in world space.

using UnityEngine;

public class MatrixExample : MonoBehaviour
{
    void Start()
    {
        Matrix4x4 m = Matrix4x4.TRS(new Vector3(10, 0, 0),
            Quaternion.Euler(0, 90, 0), Vector3.one * 2);
        Vector3 point = m.MultiplyPoint3x4(Vector3.forward);
        Vector3 direction = m.MultiplyVector(Vector3.forward);
        Debug.Log($"Point: {point}; direction: {direction}"); // (12,0,0); (2,0,0)
        Debug.Log(m.inverse.MultiplyPoint3x4(point)); // approximately (0,0,1)
    }
}

Composition: order matters

parent * child first applies the child transform, then the parent. Changing the order changes the result: moving then rotating can orbit an object around the origin; rotating then moving places it at a fixed position. A parent's rotation also turns its child's local translation.

Matrix4x4 parent = Matrix4x4.TRS(new Vector3(5, 0, 0),
    Quaternion.Euler(0, 90, 0), Vector3.one);
Matrix4x4 child = Matrix4x4.Translate(new Vector3(0, 0, 2));
Matrix4x4 world = parent * child;
Vector3 childOrigin = world.MultiplyPoint3x4(Vector3.zero); // (7,0,0)

Going further: what is inside the matrix?

You can skip this section on your first read. An affine transform moves, turns, scales or slants a shape without adding perspective. Homogeneous coordinates add one extra number so the same calculation can handle both positions and directions.

A mesh stores vertices relative to its own origin. An object-to-world matrix converts those local positions into scene positions. Unity uses column vectors: world = matrix * local. The fourth coordinate, w, distinguishes a point (1) from a direction (0), so translation moves points but does not move directions.

For an affine transform, columns 0–2 are the transformed local X, Y and Z axes; column 3 holds translation. The bottom row is (0, 0, 0, 1). The indexer is m[row, column]; memory storage is column-major. You rarely need to set the 16 entries yourself.

A normal is an arrow pointing straight out of a surface. Non-uniform scale means stretching by different amounts on different axes, such as making a shape taller without making it wider.

Going further: Normals are different from directions

With non-uniform scale, applying the ordinary matrix to a normal can make it stop being perpendicular to its surface. Use the inverse transpose and normalize. For a surface tangent, the ordinary vector transform is appropriate. Negative scale can reverse triangle winding; shear can appear when rotated children inherit non-uniform scale.

Vector3 worldNormal = objectToWorld.inverse.transpose
    .MultiplyVector(localNormal).normalized; // objectToWorld must be invertible

Going further: Projection matrices

Camera projection maps view coordinates into clip space, before perspective division. Perspective makes distant objects appear smaller; orthographic projection does not. Do not use MultiplyPoint3x4 for a perspective matrix. GPU projection conventions vary by graphics API; use Unity shader helpers or GL.GetGPUProjectionMatrix when supplying custom GPU projection matrices.

What happens at runtime

  1. C# builds or reads a matrix value.
  2. The rendering code sends transformation data to the GPU.
  3. The vertex shader transforms each vertex; the mesh's stored vertex array stays unchanged.

Common Mistakes

  • Using new Matrix4x4() as a no-op: use identity.
  • Using point multiplication on a velocity: translation should not affect it.
  • Normalizing a scaled vector when its magnitude is meaningful, such as velocity.
  • Assuming every matrix can be cleanly split into position, rotation and scale: shear and projection do not fit that model.
