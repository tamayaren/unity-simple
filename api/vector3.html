Vector3

A Vector3 is three numbers: x, y and z. Unity uses it for two different things: a position (a point in the world) and a direction with a length (like velocity: "this way, this fast").

A position is a pin on a map. A direction is an arrow drawn on the map: it points somewhere and has a length, but you can draw it anywhere. Subtracting two pins (b - a) gives you the arrow from pin a to pin b.

Constructors

Vector3 v = new Vector3(1f, 2f, 3f);

Static Properties (shortcuts)

NameValue
Vector3.zero(0, 0, 0)
Vector3.one(1, 1, 1)

Vector3.right / left(1, 0, 0) / (-1, 0, 0)

These are world directions. For the direction an object is facing, use transform.forward.

Code Samples

Chase the player

using UnityEngine;

public class Chaser : MonoBehaviour
{
    [SerializeField] private Transform player;
    [SerializeField] private float speed = 3f;

    void Update()
    {
        // Step toward the player. MoveTowards stops exactly on target, no jitter.
        transform.position = Vector3.MoveTowards(
            transform.position, player.position, speed * Time.deltaTime);
    }
}

Direction and distance

Vector3 toPlayer = player.position - transform.position; // arrow from me to player
float distance = toPlayer.magnitude;                     // how far
Vector3 direction = toPlayer.normalized;                 // which way (length 1)

Fast range check

float range = 10f;
// Compare squared values: avoids a square root every frame.
if ((player.position - transform.position).sqrMagnitude < range * range)
{
    Debug.Log("In range");
}

Is the player in my field of view?

Vector3 toPlayer = (player.position - transform.position).normalized;
float dot = Vector3.Dot(transform.forward, toPlayer);
if (dot > 0.5f) // roughly within 60 degrees either side of forward
{
    Debug.Log("I can see you");
}

Diagonal movement that isn't faster

Vector3 input = new Vector3(Input.GetAxisRaw("Horizontal"), 0f, Input.GetAxisRaw("Vertical"));
// Pressing W+D gives (1, 0, 1), which has length 1.41. That's 41% faster diagonally.
input = Vector3.ClampMagnitude(input, 1f);
transform.position += input * speed * Time.deltaTime;

What happens at runtime

Vector3 is a struct, which means it's copied whenever you assign it or pass it to a method, like an int. Changing a copy doesn't change the original:

Vector3 p = transform.position; // p is a copy
p.y = 10f;                      // changes only the copy
transform.position = p;         // now the object moves

Vector3 math is very cheap and creates no garbage, so it's fine to use freely in Update.

Common Mistakes

  • Lerp with a constant t in Update (Lerp(a, b, 0.1f)) moves fast at first and slows down forever without quite arriving, and speed depends on frame rate. For constant speed, use MoveTowards; for smooth easing, use SmoothDamp.
  • Normalizing a zero vector. Vector3.zero.normalized is (0,0,0), not an error, but it may not be what you expected.
  • Mixing up world and local directions. Vector3.forward is always world +Z. Use transform.forward for "where I'm facing".
