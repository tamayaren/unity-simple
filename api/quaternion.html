Quaternion

A Quaternion stores a rotation. Internally it's four numbers (x, y, z, w) that you should never edit directly. Instead, you create and combine rotations with the helper methods on this page. You can think in degrees and let Unity do the math.

Describing a rotation as three angles (X, Y, Z) is like steering with three dials, one per axis. It works most of the time, but in some positions two dials end up turning the same way and you lose one direction of control. This is called gimbal lock. A quaternion is more like saying "point along this arrow, then twist this much". It has no dials, so nothing can jam. You don't need to understand the four numbers, just like you don't need to understand a car engine to drive.

Operators

a * bCombine: first apply b, then a. Order matters: a * b is usually not the same as b * a.

Code Samples

Setting a rotation with degrees

transform.rotation = Quaternion.Euler(0f, 90f, 0f); // face +X (turned right 90 degrees)

Turn smoothly to face a target (turret)

using UnityEngine;

public class SmoothTurret : MonoBehaviour
{
    [SerializeField] private Transform target;
    [SerializeField] private float turnSpeed = 90f; // degrees per second

    void Update()
    {
        Vector3 dir = target.position - transform.position;
        dir.y = 0f; // stay level: only turn left/right
        if (dir == Vector3.zero) return;

        Quaternion wanted = Quaternion.LookRotation(dir);
        transform.rotation = Quaternion.RotateTowards(
            transform.rotation, wanted, turnSpeed * Time.deltaTime);
    }
}

Spawn a bullet with a random spread

Quaternion spread = Quaternion.Euler(Random.Range(-3f, 3f), Random.Range(-3f, 3f), 0f);
Instantiate(bulletPrefab, muzzle.position, muzzle.rotation * spread);

Keep your own angle instead of reading eulerAngles

using UnityEngine;

public class MouseLook : MonoBehaviour
{
    [SerializeField] private float sensitivity = 2f;
    private float pitch; // up/down, kept by us so it never "flips"
    private float yaw;   // left/right

    void Update()
    {
        yaw   += Input.GetAxis("Mouse X") * sensitivity;
        pitch -= Input.GetAxis("Mouse Y") * sensitivity;
        pitch  = Mathf.Clamp(pitch, -80f, 80f); // don't look past straight up/down

        transform.rotation = Quaternion.Euler(pitch, yaw, 0f);
    }
}

What happens at runtime

  1. Quaternion.Euler(x, y, z) converts your degrees into a quaternion. Unity applies them in the order Z, then X, then Y.
  2. When you read eulerAngles, Unity converts back. Many different sets of angles describe the same rotation, so you might get (180, 0, 180) where you expected (0, 180, 0). Both are correct; they're just two ways of writing it.
  3. Like Vector3, Quaternion is a struct: it's copied on assignment and creates no garbage.

Common Mistakes

  • Setting x/y/z/w directly. rotation.y = 90 does not mean 90 degrees. Use Quaternion.Euler.
  • Adding to eulerAngles every frame and reading them back. Can jump or flip near 90 degrees on X. Keep your own float angles (see the MouseLook example).
  • LookRotation(Vector3.zero) logs "Look rotation viewing vector is zero". Check that the direction isn't zero first.
  • Wrong multiplication order. transform.rotation * extra rotates around the object's own axes; extra * transform.rotation rotates around world axes.
