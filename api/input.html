Input

The Input class reads the keyboard, mouse and simple gamepad input using the old Input Manager. It's simple and used in most tutorials. For new projects, also look at the Input System.

Requires the old system to be enabledIf Project Settings > Player > Active Input Handling is set to "Input System Package (New)", every call on this page throws an InvalidOperationException. Set it to "Both" to use this class. See Handling Input.

Down, held, up

Most methods come in three flavors:

SuffixTrue whenUse for
...DownOnly on the one frame the key was pressedJump, shoot once, open menu
(none)Every frame while heldSprint, automatic fire, charging
...UpOnly on the frame it was releasedRelease a charged attack

Code Samples

Top-down movement

using UnityEngine;

public class TopDownMove : MonoBehaviour
{
    [SerializeField] private float speed = 5f;

    void Update()
    {
        float x = Input.GetAxisRaw("Horizontal");
        float z = Input.GetAxisRaw("Vertical");
        Vector3 dir = new Vector3(x, 0f, z).normalized; // normalized: diagonals aren't faster
        transform.position += dir * speed * Time.deltaTime;
    }
}

Charge-and-release attack

private float chargeStart;

void Update()
{
    if (Input.GetMouseButtonDown(0)) chargeStart = Time.time;

    if (Input.GetMouseButtonUp(0))
    {
        float charge = Mathf.Clamp01((Time.time - chargeStart) / 2f); // full after 2 s
        Debug.Log("Released with " + (charge * 100f) + "% power");
    }
}

What happens at runtime

  1. At the start of each frame, Unity reads the OS input events and updates key states.
  2. GetKeyDown is true for that single frame only. If you check it in FixedUpdate and no physics step runs that frame, you never see it.
  3. GetAxis doesn't jump straight to 1. It moves toward it at the "Sensitivity" speed set in Project Settings > Input Manager, and back toward 0 at the "Gravity" speed.

Common Mistakes

  • Checking ...Down in FixedUpdate. Presses get missed. Check in Update.
  • Typos in axis names. GetAxis("horizontal") (lowercase) throws "Input Axis horizontal is not setup". Names are case-sensitive.
  • Hard-coding keys everywhere. Fine for learning; for real games, the Input System makes rebinding and gamepad support much easier.
