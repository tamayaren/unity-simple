AudioSource

An AudioSource plays sounds (AudioClips) from a position in the world. An AudioListener, usually on the main camera, acts as the player's ears. Both are needed to hear anything.

The AudioSource is a speaker you place in the world, the AudioClip is the song file, and the AudioListener is a microphone in the player's head. Play() is putting a CD in the speaker and pressing play: if you press play again, it restarts. PlayOneShot() is having the speaker shout a quick word on top of whatever is playing.

Code Samples

Footsteps and hit sounds

using UnityEngine;

[RequireComponent(typeof(AudioSource))]
public class PlayerSounds : MonoBehaviour
{
    [SerializeField] private AudioClip[] footsteps;
    [SerializeField] private AudioClip hurtSound;
    private AudioSource source;

    void Awake()
    {
        source = GetComponent<AudioSource>();
    }

    // Call from an Animation Event on each foot contact.
    public void Footstep()
    {
        AudioClip clip = footsteps[Random.Range(0, footsteps.Length)];
        source.pitch = Random.Range(0.9f, 1.1f);
        source.PlayOneShot(clip, 0.6f);
    }

    public void Hurt()
    {
        source.PlayOneShot(hurtSound);
    }
}

Coin pickup that plays a sound after it's destroyed

void OnTriggerEnter(Collider other)
{
    if (!other.CompareTag("Player")) return;
    // The AudioSource on this coin would be destroyed with it, cutting the sound off.
    AudioSource.PlayClipAtPoint(pickupSound, transform.position);
    Destroy(gameObject);
}

What happens at runtime

  1. Play / PlayOneShot queue the sound; the audio system mixes it on a separate thread, so it keeps playing smoothly even during frame drops.
  2. Each frame, Unity compares every 3D AudioSource's position to the AudioListener's to set volume and left/right balance.
  3. Destroying or deactivating the GameObject stops all its sounds immediately.
  4. With Time.timeScale = 0, audio keeps playing. Pause it yourself if needed (or set AudioListener.pause = true).

Common Mistakes

  • No sound at all. Is there an AudioListener in the scene? Is spatialBlend 1 with the source far away? Is the Game view's audio muted?
  • "There are 2 audio listeners in the scene". A second camera also has one. Remove the extra AudioListener component.
  • Using Play() for rapid effects (gunshots). Each call cuts off the last. Use PlayOneShot.
  • Sound plays on start unexpectedly. Untick Play On Awake.
