Collider

A Collider gives an object an invisible physical shape. It's what raycasts hit, what Rigidbodies bump into, and what triggers detect. The shape doesn't have to match the visible mesh exactly; simple shapes are faster.

Collider types

TypeShapeSpeedUse for
BoxColliderBoxFastCrates, walls, buildings
SphereColliderBallFastestBalls, pickup ranges
CapsuleColliderPillFastCharacters
MeshColliderMatches a meshSlowComplex static level geometry. Needs Convex on for dynamic Rigidbodies.

For complex moving objects, add several primitive colliders on child objects (a compound collider) instead of one Mesh Collider.

Events (messages on your scripts)

Write these methods on a script on the same GameObject as the collider (or on the GameObject with the Rigidbody).

MessageParameterCalled when
OnCollisionEnterCollisionStarted touching (solid).
OnCollisionStayCollisionEvery physics step while touching.
OnCollisionExitCollisionStopped touching.
OnTriggerEnterColliderSomething entered a trigger.
OnTriggerStayColliderEvery physics step while inside.
OnTriggerExitColliderSomething left a trigger.

Code Samples

Damage zone (trigger)

using UnityEngine;

public class LavaZone : MonoBehaviour
{
    [SerializeField] private int damagePerSecond = 20;

    void OnTriggerStay(Collider other)
    {
        if (other.TryGetComponent(out Health health))
        {
            // OnTriggerStay runs each physics step, so scale by the step length.
            health.TakeDamage(damagePerSecond * Time.fixedDeltaTime);
        }
    }
}

Spawn sparks where a bullet hits

using UnityEngine;

public class ImpactEffect : MonoBehaviour
{
    [SerializeField] private GameObject sparksPrefab;

    void OnCollisionEnter(Collision collision)
    {
        ContactPoint contact = collision.GetContact(0);
        // Point the sparks out of the surface.
        Quaternion rot = Quaternion.LookRotation(contact.normal);
        Instantiate(sparksPrefab, contact.point, rot);
        Destroy(gameObject);
    }
}

Ground check with a trigger under the feet

using UnityEngine;

// Put this on a small trigger collider child object at the character's feet.
public class GroundSensor : MonoBehaviour
{
    public bool IsGrounded => contacts > 0;
    private int contacts;

    void OnTriggerEnter(Collider other) { if (!other.isTrigger) contacts++; }
    void OnTriggerExit(Collider other)  { if (!other.isTrigger) contacts--; }
}

What happens at runtime

  1. Each physics step, the engine checks which colliders overlap or touch.
  2. For solid collisions, it pushes Rigidbodies apart and adjusts their velocity (friction, bounce).
  3. It compares this step's contacts with the last step's: new pairs get Enter, continuing pairs get Stay, ended pairs get Exit.
  4. Messages are sent to scripts on both objects. On a child collider of a Rigidbody, messages go to the Rigidbody's GameObject.
  5. Disabling or destroying a collider while inside a trigger does not call OnTriggerExit. Keep that in mind for counters like the ground sensor above.

Common Mistakes

  • No callback at all. Check: at least one object has a Rigidbody; both are 3D (or both 2D); the method signature is exactly right; the layers are allowed to collide in the Layer Collision Matrix.
  • OnTriggerEnter(Collision c): wrong parameter type. Triggers get a Collider.
  • Scaling colliders to negative values or very thin shapes. Causes missed collisions. Use the collider's own Size/Radius fields.
