Camera

A Camera decides what the player sees. It also converts between screen positions (pixels, like where the mouse is) and world positions (where things are in the scene).

The camera is a window you look through at the world. The screen is the glass. ScreenPointToRay is putting your finger on the glass and asking "what am I pointing at out there?" WorldToScreenPoint is the reverse: "where on the glass do I see that tree?"

Code Samples

2D: move an object to the mouse

using UnityEngine;

public class FollowMouse2D : MonoBehaviour
{
    private Camera cam;

    void Awake() { cam = Camera.main; } // cache it

    void Update()
    {
        Vector3 mouse = Input.mousePosition;
        mouse.z = -cam.transform.position.z; // distance from camera to the z = 0 plane
        Vector3 world = cam.ScreenToWorldPoint(mouse);
        transform.position = new Vector3(world.x, world.y, 0f);
    }
}

Health bar over an enemy's head (Screen Space UI)

[SerializeField] private Transform enemyHead;
[SerializeField] private RectTransform healthBarUI;

void LateUpdate()
{
    Vector3 screen = Camera.main.WorldToScreenPoint(enemyHead.position);
    bool inFront = screen.z > 0f;
    healthBarUI.gameObject.SetActive(inFront);
    if (inFront) healthBarUI.position = screen;
}

Is an object on screen?

Vector3 v = cam.WorldToViewportPoint(target.position);
bool onScreen = v.z > 0f && v.x >= 0f && v.x <= 1f && v.y >= 0f && v.y <= 1f;

What happens at runtime

  1. After LateUpdate, every enabled camera renders what it can see on its cullingMask layers, between its near and far clip planes.
  2. That's why camera movement belongs in LateUpdate: everything has moved for this frame, and the camera renders right after.
  3. Camera.main is cached by Unity in recent versions, so it's cheap, but it's still tidy to store it in a field.

Common Mistakes

  • Camera.main is null. Your camera isn't tagged "MainCamera".
  • ScreenToWorldPoint always returns the camera position. You left z = 0. For a perspective camera, z must be how far in front of the camera you want the point.
  • Jittery follow camera. Move it in LateUpdate, and if following a Rigidbody, turn on Interpolate on that Rigidbody.
  • For polished cameras, consider the Cinemachine package: follow, look-at, screen shake and blending between shots without code.
