Mathf

Mathf is a toolbox of math functions for float numbers: clamping, rounding, smooth movement, trigonometry and more. It's Unity's version of C#'s System.Math, but works with float instead of double.

Code Samples

Health that can't go below 0 or above max

currentHealth = Mathf.Clamp(currentHealth - damage, 0, maxHealth);

A floating, bobbing pickup

using UnityEngine;

public class Bob : MonoBehaviour
{
    [SerializeField] private float height = 0.25f;
    [SerializeField] private float speed = 2f;
    private Vector3 startPos;

    void Start() { startPos = transform.position; }

    void Update()
    {
        // Sin goes smoothly between -1 and 1 as time passes.
        float offset = Mathf.Sin(Time.time * speed) * height;
        transform.position = startPos + Vector3.up * offset;
    }
}

Health bar fill amount

// Turn "37 out of 120" into a 0-1 value for a UI Image's fillAmount.
healthBar.fillAmount = Mathf.InverseLerp(0, maxHealth, currentHealth);

2D: rotate a sprite to face the mouse

Vector3 mouse = Camera.main.ScreenToWorldPoint(Input.mousePosition);
Vector2 dir = mouse - transform.position;
float angle = Mathf.Atan2(dir.y, dir.x) * Mathf.Rad2Deg;
transform.rotation = Quaternion.Euler(0f, 0f, angle);

Common Mistakes

  • Comparing floats with ==. Float math has tiny rounding errors, so 0.1f + 0.2f == 0.3f can be false. Use Mathf.Approximately(a, b) or check Mathf.Abs(a - b) < 0.01f.
  • Passing degrees to Sin/Cos. Mathf.Sin(90) is not 1. Use Mathf.Sin(90 * Mathf.Deg2Rad).
  • Integer division. currentHealth / maxHealth with two ints is 0 until it's 1. Cast one to float: (float)currentHealth / maxHealth.
  • Expecting Sign(0) to be 0. Mathf.Sign returns 1 for zero.
