Libraries are like power tools. You could build a bookshelf with a hand saw, but a drill someone else already built saves hours. The trick is knowing which tools are worth having, and not buying ten drills that all do the same thing.

Before you install anything

Check that it's still updated and works with your Unity version, read its licence (everything below is free to use in commercial games at the time of writing, but licences can change), and use version control so you can undo an install. Add one library at a time.

How to install packages

Where it's fromHow
Unity Registry (Unity's own)Window > Package Manager > Unity Registry > find it > Install.
Asset StoreClick Add to My Assets on the website, then in Package Manager open My Assets > Download > Import.
GitHubPackage Manager > + > Install package from git URL, and paste the URL from the project's README. (Needs Git installed.)
OpenUPMA free catalogue of open-source packages. See openupm.com for the steps.

Nicer Inspector

LibraryWhat it doesGet it
NaughtyAttributesAdds attributes like [Button] (a clickable button in the Inspector that runs a method), [ShowIf], [ReadOnly] and dropdowns.GitHub · Asset Store
Tri-InspectorSimilar idea with groups, tabs and validation. A free alternative to the paid Odin Inspector.GitHub
using NaughtyAttributes;
using UnityEngine;

public class Spawner : MonoBehaviour
{
    [SerializeField] private bool useTimer;
    [SerializeField, ShowIf("useTimer")] private float interval = 2f; // only shown when useTimer is ticked

    [Button] // a "Spawn Now" button appears in the Inspector
    private void SpawnNow() { Debug.Log("Spawned!"); }
}

Should I use a library or build it myself?

Use a library when…Build it yourself when…
It's a hard, solved problem (cameras, tweening, networking)It's small and specific to your game
You want to finish the gameYou want to learn how it works (see Building Your Own Systems)
It's popular and actively maintainedThe library is abandoned or much bigger than what you need

Common Mistakes

  • Installing ten libraries on day one and never learning the basics.
  • Two libraries that do the same job (two tween libraries, two inspector libraries).
  • Downloading "free" paid assets from random websites. They can contain malware and are illegal to ship.
  • Not reading the README, then wondering why the git URL install fails.
