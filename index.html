A beginner-friendly rewrite of the Unity documentation. Every page explains what an API does, shows how to use it with a working example, and describes what actually happens while your game is running.

Disclaimer: AI-assisted content

The pages on this site were written with the help of AI, which was used to interpret and simplify the official Unity documentation. We try to keep everything accurate, but simplification can leave out details and mistakes are possible.

Which Unity version?

Examples target Unity 6 and use C#. The pages assume you know basic C# (variables, methods, classes, if statements) but are new to Unity. Most of it also works in Unity 2021 and 2022. When a name changed in Unity 6 (for example Rigidbody.velocity became Rigidbody.linearVelocity), the page says so.

How to read an API page

API pages follow the same layout so you always know where to look:

  • Infobox (top right): what kind of type it is, what it inherits from, and which namespace to put in your using line.
  • Summary: what it is, in one or two plain sentences.
  • Think of it like...: a real-world comparison for the trickier ideas, shown in a purple box.
  • Properties / Methods / Events: tables of the members you will actually use. Rarely used members are left out.
  • Code Samples: complete scripts you can copy into a project.
  • What happens at runtime: what Unity does behind the scenes, step by step.
  • Common Mistakes: the things that trip most beginners up.
